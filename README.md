# Streaming Platform ELT Pipeline

An end-to-end cloud ELT pipeline built using AWS S3, Snowflake and dbt, using the MovieLens dataset to simulate the type of data processing workflow applicable to a modern streaming platform.

The project covers cloud-based data ingestion, Snowflake warehousing, dbt transformations, data quality testing and analytics-oriented data modeling.

Dataset note: This project uses the publicly available MovieLens dataset. Netflix is used as a conceptual use case to demonstrate how a streaming platform's data could be ingested, transformed and modeled; the dataset is not Netflix proprietary data.
